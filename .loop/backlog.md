# backlog

ループが**上から1件**取る。書式と規約は [LOOP.md](./LOOP.md) を参照。

投入するときは**1周で終わる粒度**にする。「認証基盤一式」ではなく
「ログインAPI + ログインフォーム」まで割る。粒度が大きいと機械ゲートに
到達する前に文脈が尽きる。

すべてのタスクに **`見て確かめること:`** を書く（省略不可）。コードを読まずに
人が確認できる受け入れ条件で、出力ゲートの判定基準になる。書けないタスクは
粒度が誤っている。詳細は [LOOP.md](./LOOP.md)。

このファイルには**実タスク以外の `- [ ]` を置かない**。
書式サンプルもコメントアウトした例も置かない。ループは先頭の `- [ ]` を
無条件に取るので、サンプルがあればサンプルを作りにいく。
